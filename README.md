# Generation Gap Atlas / 世代間格差アトラス

公開サイト: https://nobby11334.github.io/generationgapatlas/

日本の就職氷河期世代と前後の世代を、公開統計と政府資料に基づき比較・検証する独立したオープンデータプロジェクト。

## 現在の実装（初版）
- **概観**：2025年の就職氷河期中心層（1974〜1983年生まれ）の政府公表KPIを表示。
- **世代比較**：比較可能な一次統計が揃わない指標は未掲載と明示。
- **政策トラッカー**：2026〜2028年度の新支援プログラム、雇用、訓練、社会参加、高齢期支援、終了済み地域交付金を整理。
- **政策効果測定**：政策実施、アウトカムの観測値、因果効果の判定を分離。未測定は未判定として表示。
- **特別年金シミュレーター**：対象人数、月額、給付開始・終了年齢から単純な年間・累積支給額を試算。
- **資料・方法論**：出典・限界・データ取り扱いを説明。

## KPIの定義
- 正規雇用労働者率 71.2%（2025年）：1974〜1983年生まれ、役員を除く雇用者に占める正規従業員の割合。
- 不本意非正規雇用労働者率 8.8%（2025年）：同出生層の非正規従業員のうち「正規の仕事がないから」を主な理由とした人の割合。**全人口に占める割合ではありません。**

## 推計と実測の区分
「2026年新支援プログラムの効果」は現時点で因果推定していません。KPIや採用件数の前後比較だけでは政策効果を証明できません。50歳からの特別給付は現行制度ではなく、利用者入力による政策シナリオです。財政試算は単純化されたグロス給付であり、人口動態、税・社会保険料、現在価値、既存制度との調整を含みません。

## 公開・更新
GitHub Actions (.github/workflows/deploy.yml) が main push 時にGitHub Pagesへデプロイします。**デプロイの自動化と統計データの自動取得は別**です。初版では一次資料を検証して手動反映しています。誤った自動更新を避けるため、公開データを無検証で転載する処理は設けていません。

## 今後の拡張
1. 労働力調査・賃金構造基本統計調査・全国家計構造調査から、世代別に比較可能な長期時系列を取り込む。
2. 公的な政策KPIの年度別結果、予算・決算、受益者数を構造化し、根拠URLと取得日を管理。
3. 政策介入前後の系列比較・対照群設定を行い、因果推定の成立要件を開示。
4. 年金・税・所得の生涯シミュレーターを拡張し、制度案ごとの受益分布と負担分布を示す。
5. 機械検証済みの公開データ更新ワークフローを追加。

政治的立場や特定世代の優劣を示すことを目的とせず、検証可能な事実と政策選択肢を提供します。

### カバレッジの限界
「完全網羅」は現状達成していません。政府の全施策、全年度・全自治体の執行額、正規・非正規を含む全年代の賃金・資産系列、2026年10月の最新KPI結果については未完成です。公開データの無い項目は推測で埋めず、未収録・未公開・照合未了を区別する必要があります。特に予算額と支出額の合算は行っていません。

### データ更新とデプロイの品質保証
- `scripts/validate_site.py` がファイル・件数・整合性・JavaScript構文を検査。失敗すればPagesデプロイを中止。
- 152事業・207自治体の原票取得はGitHub Actionsで再検証し、成功した場合のみデータを更新。
- 10月会議の全15公開PDF索引とKPI報告全8ページ本文もGitHub Actionsで更新可能。
- **自動更新対象は既知の原票URL**です。新しい年度や新しい統計の自動発見、すべての新規政府資料の自動反映はまだ保証していません。

### 公表データだけでは埋められない項目
個人の生涯所得・生涯納税額・実際の厚生年金加入履歴、個別施策の税・社会保険込みの純受益、就職時代という因果の厳密な分離、全自治体の確定支出・利用者別成果は、公開統計だけで個人別に確定できません。観測値・推計値・未確認を分けて表示します。

## 三軸分析（2026-11-12）
「三つの格差を検証」タブでは、以下の三軸を独立して比較する。

1. **就職時の機会格差**: `data/first-job-cohorts.json`。1987〜2013年卒、男性・高校／専門学校／短大高専／大学／学歴計の初職正規率、非正規率。社研パネル調査の初職大企業比率・3年以内離職率は別標本として提示。出典：[厚労省2024年12月24日年金部会資料](https://www.mhlw.go.jp/content/12401000/001362107.pdf)。
2. **現在の経済格差**: 出生年別実質賃金、2025年の年齢階級別正規雇用率、家計資産。出生年固定か横断の年齢比較かを明記し、統計定義を混合しない。
3. **累積した不利益**: `data/pension-cohort-projections.json`（2024年年金財政検証・過去30年ケースを用いた出生年度別推計）。失われた所得については利用者が毎月の差額と年数を設定する仮定シナリオを示す。仮定額を実際の生涯損失・補償額とは表示しない。

### 評価上の重大な注意
- 就職時に正規職へ入れた層だけの平均賃金は、就職機会を得られなかった人々の不利益を含まない（選択バイアス）。
- 現在の雇用比率が近くても生涯所得・年金加入機会が回復したことにはならない。
- 逆に、初職に不利があったことだけから現在の世代全員の損害を推定することもできない。
- 年金モデルの金額・加入年数は将来の制度・就業の仮定を含み、確定した受給額ではない。

## 所得分布・二極化分析（2026年11月12日追加）

- **原票**：総務省・2022年就業構造基本調査 [全国表40](https://www.e-stat.go.jp/dbview?sid=0004008157)、[直接取得する公表Excel](https://www.e-stat.go.jp/stat-search/file-download?fileKind=0&statInfId=000040077301)
- **再現可能なデータ処理**：`scripts/import_income_distribution.py` は公表XLSXをPython標準ライブラリで読み込み、`data/income-distribution-2022.json` に集計。16所得階級×10年齢帯×男女計・男・女×有業者・正規・非正規＝90分布。欠損者数を保持し、不明な値を補完しない。
- **表示**：「所得分布・二極化」タブ。所得階級16区分のヒストグラム、年齢帯の比較、低所得（年収200万円未満）・中間所得（300万〜799万円）・高所得（1000万円以上）の割合、分位点が属する所得階級、正規・非正規別比較。
- **ジニ係数**：所得階級の中点を代表値とする集計表からの近似値のみ。1500万円以上の階級代表額を1750万円と2500万円に置いた感度分析であり、**公式ジニ係数・真の範囲・信頼区間ではない**。
- **制限**：有業者の主な仕事の年間収入・収益の分布であり、無業者を含む世代全体や全所得・家計所得ではない。2022年時点の年齢横断であり厳密な出生コーホート比較でもない。単年比較から二極化の「進行」は判定しない。
- **自動品質検査**：90分布×16階級の集計値・所得不明と判明の合計・画面用JSを`scripts/validate_site.py`でチェックし、欠損・不整合時にはPages公開を中止。

2022年45〜49歳・男女計・有業者では、所得判明者に占める主な仕事の収入200万円未満が25.1%、正規職員・従業員で3.7%、非正規職員・従業員で72.7%。これは雇用形態別の分布の違いを示すものだが、これ自体が時系列的な二極化の証拠とは限らない。

## 2002・2012・2022年の所得分布の時系列（2026年11月追加）

### 実装内容
- `data/income-distribution-history.json`：総務省「就業構造基本調査」2002年・2012年・2022年の個人の主な仕事からの年間所得を**共通15階級**へ統合。10年齢帯×男女計/男/女×有業者/正規雇用×3年次＝**180分布**。
- `scripts/import_income_history.py`：各年公表ファイルを直接取得し、年齢・男女・雇用形態・所得階級を構造化。元の総数と所得階級合計の整合を検査し、欠損者数を保持。古いXLS形式の読み取りに `xlrd==2.0.2` を使用。
- `.github/workflows/import-income-history.yml`：変更時・手動で元データを再取得し、180系列の検証が通った場合だけ更新。
- 表示画面「所得分布・二極化」：同一年齢での3時点横断比較、および年齢帯を10年ずらした出生年代の**近似**追跡。16→15階級へ統一。性別、正規雇用の選択、低所得200万円未満・中間300〜799万円・高所得1000万円以上の各構成比、母集団の所得不詳率、3時点の増減を表示。
- 2002年「1000〜1499万円」階級に合わせ、2012・2022年の「1000〜1249万円」「1250〜1499万円」を統合。
- CPIに基づく**2022年購買力基準の閾値補正**を参考推計として併設。CPIの指数は2002年95.8、2012年94.5、2022年102.3（2020年=100）。所得階級内を一様とする近似を用いる。公式の実質所得分布ではない。

### 重要な統計的制限
- 2002・2012・2022年の所得分布は**別個の横断調査**で、出生集団近似の軌跡は同一人の追跡ではない。
- 「200万円未満」「1000万円以上」という固定名目閾値での20年比較は物価と賃金水準の変化による影響を受けるため、別途CPI補正を参考値として示す。
- 2002年の雇用形態表の「正規以外」と2022年の「非正規」を同一定義とみなさない。3時点比較では**有業者全体と正規職員**に限定し、2022年単年の別画面は正規・非正規双方を表示。
- 所得不詳は割合の分母から除外するが、実人数・欠損率を常に表示する。
- 無業者は所得分布の母集団に入らない。**就職機会に恵まれなかった人の全損失を示すものではない**。
- 同年齢帯横断比較では中間層の推移を見られるが、年齢・就業時間・産業・学歴構成の差を調整していない。
- 二極化の可否は閾値の定義に左右されるため、サイトに示す「三層の同時拡大・縮小」は記述的判定であり、統計的有意性を検定した結論ではない。
